# frontend

## Project setup
```
node --version # use Node 22+
corepack enable
pnpm install
```

### Compiles and hot-reloads for development
```
pnpm run serve
```

### Preview a production build locally
```
pnpm run preview
```

### Compiles and minifies for production
```
pnpm run build
```

### Run your tests
```
pnpm run test:unit
```

### Lints and fixes files
```
pnpm run lint
```

### Run your unit tests
```
pnpm run test:unit
```
